# Shaar --- Documento Estratégico de Identidade Visual e Marca (v2)

> **Versão 2.0 --- Base para construção do Brand Book**

------------------------------------------------------------------------

# 1. Essência da Marca

## Nome

**Shaar (שער)** significa **"portão"** em hebraico.

Mais do que um nome, Shaar representa a passagem entre dois momentos:

> expectativa → experiência

A empresa não vende tecnologia. Ela abre portas para experiências.

------------------------------------------------------------------------

# 2. Propósito

## Missão

Tornar o acesso a eventos mais seguro, simples e justo para
organizadores e participantes.

## Visão

Ser a infraestrutura padrão de acesso a experiências na América Latina.

## Promessa

Acesso confiável a experiências, com tecnologia invisível.

------------------------------------------------------------------------

# 3. Posicionamento

Shaar é uma plataforma B2B2C de ingressos digitais.

A tecnologia Web3 permanece completamente nos bastidores.

O cliente compra um ingresso.

O organizador vende uma experiência.

O NFT apenas garante segurança, autenticidade e propriedade.

A marca deve ser percebida como um SaaS moderno, semelhante à Stripe,
Linear ou Notion, e não como uma empresa de criptomoedas.

------------------------------------------------------------------------

# 4. Valores

-   Confiança acima de tudo
-   Simplicidade gera adoção
-   Transparência cria relacionamentos
-   A tecnologia deve desaparecer
-   Experiências vêm antes da infraestrutura
-   O usuário deve sentir controle e liberdade

------------------------------------------------------------------------

# 5. Personalidade

-   **60% Confiável**
-   **25% Criativa**
-   **15% Divertida**

Confiável transmite segurança operacional.

Criativa demonstra inovação.

Divertida lembra que o destino final sempre é uma experiência.

# 7. Brand Pillars

## Acesso

Abrimos portas para experiências.

## Confiança

Ingressos autênticos.

Revenda oficial.

Receita protegida.

## Fluidez

Comprar, entrar e revender devem ser processos simples.

## Liberdade

O usuário possui seu ingresso e decide como utilizá-lo.

------------------------------------------------------------------------

# 8. Conceito Central

## O Portal

O arco representa mais do que uma porta.

Representa uma transição.

Na arquitetura existe o conceito de **Threshold**, o momento de passagem
entre dois estados.

Shaar representa exatamente essa travessia.

Toda comunicação deve reforçar essa ideia.

------------------------------------------------------------------------

# 9. Direção Visual

## Logo

Um arco clássico minimalista inspirado na arquitetura romana ou grega.

O símbolo deve sugerir simultaneamente:

-   Portal
-   Entrada
-   Ticket
-   Letra S

Sem elementos cyberpunk ou associados ao universo cripto.

------------------------------------------------------------------------

# 10. Sistema Visual

Toda identidade deve nascer de apenas três formas.

○ Círculo

◖ Arco

▭ Ticket

Todos os componentes visuais derivam dessas três geometrias.

# 13. Motion Principles

Toda animação deve transmitir:

-   continuidade
-   leveza
-   abertura
-   fluidez

Evitar:

-   glitches
-   partículas
-   explosões
-   neon

------------------------------------------------------------------------

# 14. Sound Branding

O momento de validação do ingresso deve possuir uma assinatura sonora
curta, agradável e memorável.

O som deve transmitir:

-   confirmação
-   segurança
-   satisfação

Nunca agressividade.

------------------------------------------------------------------------

# 15. Interface

A interface deve ser predominantemente Light Mode.

Características:

-   muito espaço em branco
-   hierarquia clara
-   poucos elementos competindo por atenção
-   sensação de software premium

Referências:

-   Stripe
-   Linear
-   Apple
-   Notion

------------------------------------------------------------------------

# 16. Linguagem
